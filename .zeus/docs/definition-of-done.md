# Definition of Done
A change is APPROVED only when:
- source provenance + MIT LICENSE retained; no inadvertent missing upstream files;
- code and assets reflect the intended Zeus scope without breaking runtime identifiers;
- targeted tests, lint/typecheck/build and platform-relevant checks pass or are explicitly documented as unavailable;
- no keys or secrets exposed;
- PR includes base/head SHA, changed paths, test outputs, risks and review outcome;
- local functionality validated where possible; canonical checkpoint records VERIFIED facts only.
ZEUS-001 is not complete just because documentation or an import script exists. Later tasks cannot be called complete until code is built, tested and verified.
