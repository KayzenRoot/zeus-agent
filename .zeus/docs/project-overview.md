# Project Overview
Zeus Agent is KayzenRoot's own browser-first visual agent experience, derived from the MIT-licensed Hermes Agent. Develop/test on the owner's local Windows/WSL2 workstation; VPS deployment is not in this phase. First user-visible goal: coherent Zeus name and iconography in the existing frontend, without changing external integrations or functional semantics.
Upstream: https://github.com/NousResearch/hermes-agent; baseline candidate 53df274b08f2bbbe82bb67bb50c7571952e95809 (pin upon import).
